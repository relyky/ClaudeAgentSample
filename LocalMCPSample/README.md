# LocalMCPSample

本專案用於開發本地 MCP (Model Context Protocol) Server 範例。

## 專案目的

提供 MCP Server 開發的範例與實驗環境,幫助理解如何建立自訂的 MCP Server 並與 Claude Agent 整合。

## 環境需求

- **Python 3.14+**
- **uv** 套件管理器

## 快速開始

```bash
# 安裝依賴
uv sync

# 啟動 MCP Server (範例)
uv run server.py
```
